# My Budget Tracker

## Project Description

This project is a simple Budget Tracker webpage created using HTML and CSS. It allows users to view expenses, enter new expense information, choose an expense category, and view budgeting multimedia content.

## What Each Part Does

### HTML Table

The table displays expense information using semantic HTML elements including `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, and `<td>`.

### Form

The form allows users to enter an expense, select a category from a dropdown, and enter an amount. The category dropdown contains five options: Food, Transport, Bills, Entertainment, and Shopping.

### Multimedia

The page includes an image using the `<img>` element and a YouTube video using an `<iframe>`.

### CSS Styling

The `style.css` file controls the appearance of the webpage. It includes advanced CSS selectors such as descendant selectors, attribute selectors, child selectors, and the `:hover` pseudo-class.

## Files

* `index.html` — Contains the structure and content of the webpage.
* `style.css` — Contains the styling and advanced CSS selectors.
* `README.md` — Explains the project and its components.

## Technologies Used

* HTML5
* CSS3
* Semantic HTML
* Advanced CSS Selectors
# My Budget Tracker

## Project Description

My Budget Tracker is a simple web page designed to help users organize and view their budget and transactions. The project focuses on creating a clean and professional visual design using HTML and CSS.

## Files

### index.html
This file contains the structure of the Budget Tracker, including the heading, description, form, inputs, buttons, and transaction table.

### style.css
This file contains the visual styling for the Budget Tracker. It includes the color palette, Google Font, form styling, table styling, buttons, spacing, borders, padding, margins, and rounded corners.

### README.md
This file explains the project and describes what each file does.

## Design Features

- Green and white color palette
- Poppins Google Font
- Styled budget form
- Styled transaction table
- Alternating table row colors
- Styled buttons with hover effects
- Consistent spacing and padding
- Borders and rounded corners
- Clean and readable layout

## Technologies Used

- HTML5
- CSS3
- Google Fonts
